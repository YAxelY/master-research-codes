# Design decisions

One line per choice that shapes the results, with its reason and where it
lives in the code. Read it with [ARCHITECTURE.md](ARCHITECTURE.md). A new
decision is added here in the same commit as the code that implements it.
Dates marked "v3" were taken while suite v3 was written (November 2026) and
are not known more precisely.

| #   | Date       | Decision                                                                                                                        | Why                                                                                                               | Alternative not taken                                 | Where                            |
| --- | ---------- | ------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- | -------------------------------- |
| 1   | v3         | Every model uses the same encoder: ResNet-18, all four blocks, ImageNet weights                                                 | differences then come from the selection, not the backbone; truncating to two blocks cost 0.049 kappa in suite v2 | a lighter encoder for small patches                   | `models/encoder.py`                           |
| 2   | v3         | DDR images at 896 px, RSNA at 1024 px                                                                                           | dataset audit of 2026-10-22: the resolution that keeps the lesions visible within the GPU budget                  | native resolution (702 to 5 184 px on DDR)            | `config/experiments.py`, `DDR_BASE`, `RSNA_BASE` |
| 3   | 2026-11-15 | DDR: crop the retina before resizing (grey > 12, bounding box, square, black fill)                                              | stretching the whole photograph left about half of the square black                                               | stretch (still available: `IPS_DDR_GEOMETRY=stretch`) | `data/datasets.py`                          |
| 4   | 2026-11-15 | A held-out test split; the epoch is chosen on validation, the test set is used once at the end                                  | before v3 every reported number was a validation number                                                           | report the best validation score                      | `data/datasets.py`, `training/runner.py`                     |
| 5   | v3         | RSNA split 70 / 15 / 15 by an MD5 hash of the patient id with a fixed seed (42)                                                 | the split never changes with the run seed, and is the same on every machine                                       | a random split per run                                | `data/datasets.py`, `SPLIT_SEED`            |
| 6   | 2026-11-18 | Patch sizes from lesion sizes: 66 and 33 px on DDR, 300 and 150 px on RSNA                                                      | 33 px holds almost all DDR lesions; 300 px holds about half of the RSNA boxes                                     | sizes that divide the image (128, 64, ...)            | `config/experiments.py`, group `focus`           |
| 7   | 2026-11-18 | Sizes that do not divide the image: one more row and column of patches, padded with black                                       | keeps the chosen sizes without resizing the image                                                                 | crop the border, or resize the image                  | `data/tiling.py`, `TileSpec`               |
| 8   | v3         | Cross-attention aggregator with one learned query; self-attention only as an ablation                                           | the attention of the query gives each patch a score independent of the others, needed for selection               | self-attention as the main model                      | `models/attention.py`                           |
| 9   | v3         | M = 10 patches trained, candidates scored by groups of I = 128                                                                  | values of the original IPS code                                                                                   | other M values: group `focus_m`                       | `config/experiments.py`, `BASE`                  |
| 10  | v3         | Exploration without gradients, model in evaluation mode while it selects                                                        | the memory then depends on M and I, not on the image size                                                         | differentiable selection (DPS)                        | `models/selector.py`, `select`                 |
| 11  | v3         | Same batch of 16 images for every model: the full image steps per loader batch, patch models gather 4 images at a time until 16 | comparable optimisation                                                                                           | different batch sizes per model                       | `training/epoch.py`, `build_loader`          |
| 12  | v3         | Decoded images cached once as uint8; augmentation on the GPU at each epoch                                                      | decoding, not the model, set the duration of DDR runs                                                             | decode at every epoch                                 | `data/datasets.py`                          |
| 13  | 2026-11-23 | RSNA: class "No Lung Opacity / Not Normal" excluded (opacity against normal)                                                    | the supervisor's request                                                                                          | three classes collapsed to two                        | `data/datasets.py`, `rsna_exclude`          |
| 14  | 2026-11-25 | Weights, resume states and Grad-CAM maps written to `artifacts/`, not `results/`                                                | the results folder must be light enough to push as it is                                                          | one folder for everything                             | `config/experiments.py`                          |
| 15  | 2026-11-26 | Every random draw of an epoch seeded from (seed, epoch) (suite v3.1)                                                            | a run resumed after Kaggle's 12 h limit equals a run that never stopped                                           | one seed per run (v3.0: results before this date)     | `config/environment.py`, `training/runner.py`, `epoch_seed`        |
| 16  | 2026-11-26 | Strict determinism off by default, on with `IPS_DETERMINISTIC=1`                                                                | it slows training, and different GPU types differ anyway                                                          | always on                                             | `config/environment.py`                           |
| 17  | 2026-11-26 | Kaggle runs sync their resume state (every 2 epochs) and results to a private Hugging Face dataset                              | Kaggle stops after 12 h and keeps nothing between sessions                                                        | download the outputs by hand                          | `training/hub.py`, `HubMirror`             |
| 18  | 2026-11-26 | Every result stores its environment (platform, GPU, versions, code commit) and a hash of the images of each split               | results from Kaggle and from the cluster must say where they come from, and prove they used the same images       | rely on file names                                    | `config/environment.py`, `data/datasets.py`, `training/runner.py`                  |
| 19 | 2026-11-26 | The code is a package, `src/ips_suite/` (config, data, models, training, evaluation); the Kaggle notebook is generated from it (one `%%writefile` cell per module) and the cluster runs `python -m ips_suite` | one source of the code, a conventional structure, and the same code on Kaggle and on the cluster | keep the notebook as the source and convert it for the cluster | `tools/build_notebook.py`, `run-ips-suite-v3.sh` |
